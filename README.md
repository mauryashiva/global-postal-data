# global-postal-data

Local Postal Intelligence & Address Autofill Engine. Modern multi-country postal code lookup powered by 100% offline local datasets with 0 external API calls.

Supported Countries (13):
- 🇮🇳 India (IN)
- 🇨🇳 China (CN)
- 🇦🇫 Afghanistan (AF)
- 🇪🇬 Egypt (EG)
- 🇰🇷 South Korea (KR)
- 🇺🇸 United States (US)
- 🇬🇧 United Kingdom (GB)
- 🇯🇵 Japan (JP)
- 🇮🇩 Indonesia (ID)
- 🇲🇾 Malaysia (MY)
- 🇱🇰 Sri Lanka (LK)
- 🇻🇳 Vietnam (VN)
- 🇨🇦 Canada (CA)
